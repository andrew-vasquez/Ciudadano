# Design System Document

This document outlines the core aesthetic and functional principles of our user interface.

## Color Palette

Our interface operates in a **dark** mode, providing a sophisticated and comfortable viewing experience.

-   **Primary Color:** The leading color is `#0070F3`. It’s used for key interactive elements like buttons and calls to action.
-   **Secondary Color:** Supporting elements and less prominent UI components utilize `#111111`.
-   **Tertiary Color:** (No specific tertiary color defined in the theme, implied from seed/variant if not explicitly stated.)
-   **Neutral Color:** Backgrounds and structural elements are built upon `#000000`.

## Typography

The entire design system consistently uses the **Inter** typeface for all text elements.

-   **Headlines:** Displayed in **Inter**.
-   **Body Text:** Presented in **Inter**.
-   **Labels:** Utilizes **Inter**.

## Shape and Form

Our UI elements feature **moderate** rounded corners, striking a balance between sharpness and softness.

## Spacing and Layout

We maintain a **normal** level of spacing throughout the interface, ensuring clarity and readability without being overly dense or sparse.
